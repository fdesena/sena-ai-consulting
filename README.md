# Sena Consulting Website

Site institucional e ferramentas da Sena Consulting (senaconsulting.app).

**Stack:** TanStack Start (SSR) · Tailwind CSS v4 · Bun · Supabase · Vercel

## Rodando localmente

```bash
bun install
bun run dev --port 8080
# http://localhost:8080
```
